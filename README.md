# [Nome do Escritório] — Site institucional

Site estático responsivo, sem dependências de build. Para visualizar localmente, execute um servidor HTTP na pasta do projeto, por exemplo:

```powershell
py -m http.server 4173
```

Em seguida, acesse `http://localhost:4173`.

## Antes de publicar

- substitua `[Nome do Escritório]`, equipe, OAB, dados de contato e endereço;
- valide os indicadores e quaisquer depoimentos institucionais;
- conecte o formulário a um serviço de envio seguro ou backend;
- substitua o mapa pela localização exata do escritório.
